\paragraph{Data}
All data used are freely available online. Historical international football match results are taken from the \emph{International football results from 1872} dataset, available at \url{https://github.com/martj42/international_results}.

\paragraph{Artificial Intelligence (AI)} 

Generative AI tools were used to support the following aspects of this work:

\begin{itemize}
    \item \textbf{Coding Assistance}: code development, debugging and documentation;
    \item \textbf{Literature/search assistance}: locating and summarising relevant references;
    \item \textbf{Writing assistance}: rephrasing and structuring of technical prose.
\end{itemize}
